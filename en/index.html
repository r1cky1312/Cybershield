FAQ

Frequently asked questions

Will the website be mine?

Yes. With the Start plan the website is fully yours. With the subscription, if you want to leave, we hand over the files and help you with the move.

Is there a minimum term?

No long commitments: the subscription can be cancelled with short notice. We'd rather you stay because you're happy, not because you have to.

I already have a website, do you need to rebuild it?

Not necessarily. With the free audit we see what can be improved and, if needed, we only suggest the useful work, or the Security Only plan.

What happens if the website goes offline?

An automatic check monitors your website's availability. If there's a problem we notice it and restore it, using the latest backup if needed.

Do you guarantee the website will never be attacked?

Nobody can guarantee zero risk. We greatly reduce the chances with updates, secure configurations and backups, so any problem is solved quickly.

Do you also make custom programs or scripts?

Yes, small automations for your business (backups, file organisation, reports, network monitoring), always quoted with a fixed price in writing upfront. We don't sell off-the-shelf software: every script is made for your case. See how it works.

How do I pay?

Bank transfer or electronic payment, with an invoice. For monthly plans the fee is charged once a month.
