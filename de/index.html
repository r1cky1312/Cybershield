FAQ

Häufige Fragen

Gehört die Website mir?

Ja. Mit dem Paket Start gehört die Website vollständig Ihnen. Beim Abo übergeben wir Ihnen bei einem Wechsel die Dateien und helfen beim Umzug.

Gibt es eine Mindestlaufzeit?

Nein. Monatspläne können Sie jederzeit mit 30 Tagen Frist kündigen. Uns ist lieber, Sie bleiben, weil Sie zufrieden sind, nicht weil Sie müssen.

Auf wen läuft die Domain?

Auf Sie. Auch wenn die Domain im Monatsplan enthalten ist, bleibt sie auf Ihren Namen.

Wie lange dauert es, bis die Website online ist?

Meist wenige Tage, nachdem Sie uns Texte, Fotos und Öffnungszeiten geschickt haben. Den genauen Zeitraum nennen wir im Angebot.

Ich habe schon eine Website, müsst ihr sie neu machen?

Nicht unbedingt. Mit dem kostenlosen Check sehen wir, was sich verbessern lässt, und schlagen bei Bedarf nur sinnvolle Arbeiten vor, oder das Paket Nur Sicherheit.

Was passiert, wenn die Website ausfällt?

Eine automatische Prüfung überwacht die Erreichbarkeit der Website. Bei einem Problem merken wir es und stellen sie wieder her, falls nötig mit dem letzten Backup.

Garantiert ihr, dass die Website nie angegriffen wird?

Niemand kann null Risiko garantieren. Mit Updates, sicheren Einstellungen und Backups senken wir das Risiko deutlich, sodass ein eventuelles Problem schnell gelöst ist.

Wie bezahle ich?

Erst nachdem Sie das schriftliche Angebot angenommen haben: per Überweisung oder elektronischer Zahlung. Monatspläne werden einmal im Monat bezahlt.
